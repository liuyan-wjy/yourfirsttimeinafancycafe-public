# Your First Time in a Fancy Cafe

Turn one photo into a personalized AI video inspired by the “POV: your first time in a fancy cafe” trend.

**[Visit the website →](https://yourfirsttimeinafancycafe.com)**

## About

Create a short cafe skit starring the person in your photo: a first-time visitor mistakes a tiny wall-mounted table for a seat, notices how another guest uses it, and quietly climbs down.

- Upload one photo to get started.
- Create a vertical video for sharing.
- Available in English, Spanish, Portuguese, French, German, Japanese, Korean, and Simplified Chinese.

This repository is the public introduction to the website. Application source code is maintained separately.
